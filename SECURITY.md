# Security policy

DTU Compass will hold student accounts and study plans, so we take reports seriously.

## Reporting a vulnerability

**Don't open a public issue.** Report privately through GitHub: go to the [Security tab](https://github.com/Turing-Council/dtu-compass/security) and click **Report a vulnerability**.

Please include what you found, how to reproduce it, and what an attacker could do with it. We aim to reply within 7 days. We're students, so response can be slower during exam periods.

## Scope

- In scope: this repository and the deployed DTU Compass site and its MCP endpoints.
- Out of scope: DTU's own systems (kurser.dtu.dk, DTU sign-in). Report those to DTU.
- Please don't access other users' data, run load or denial-of-service tests, or use automated scanners against production.

## Supported versions

Only the latest deployed version is supported.

## Personal data

If your report involves personal data of students, tell us in the report so we can handle it under GDPR.
